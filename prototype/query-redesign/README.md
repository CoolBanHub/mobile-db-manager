# Mobile DB 查询工作台重构原型

## PRFAQ

### 产品标题

**Mobile DB 查询工作台：在 Android 手机上安全、快速地完成数据库探索与 SQL 验证。**

### 目标用户与新闻稿

Mobile DB 面向需要在通勤、值班、现场排障或离开电脑时查看数据库的开发者、DBA、运维和数据分析人员。新版查询工作台把连接上下文、SQL 编辑、元数据联想、执行控制和结果验证放进一个连续的移动任务流。用户不必在多个页面之间往返，也不必记住完整的表名、视图名和字段名：连接后即可获取数据库与 Schema，输入 `FROM` 或 `JOIN` 时按当前上下文搜索表和视图，引用对象后继续加载字段；运行结果与消息、执行计划和 Schema Assist 保持在同一屏幕的下半区。凭据仍保存在 Android 原生安全存储，WebView 只传连接 ID 和查询参数。

过去的移动 SQL 页面容易把桌面 IDE 的密度直接压缩到小屏幕：连接信息、工具按钮、编辑区和结果区互相争夺空间，关键操作缺少明确优先级。重构方案以“上下文—编写—执行—验证”四段任务为骨架。连接和数据库范围形成紧凑上下文卡片；运行是唯一高亮主操作；编辑器保留原有等宽字体、语法色彩和联想能力；结果区采用可切换但不跳页的标签。用户可以在数秒内判断自己连接了哪里、将执行什么、执行是否成功，以及下一步要查看哪个对象。

核心功能包括：六类数据库连接上下文切换；多查询标签；运行所选、运行全部、停止、Explain 与格式化；具名 JSON 参数；表、视图、字段和关键字联想；结果分页、单元格详情、复制、导出与分享；消息、执行计划和 Schema Assist；安全模式与受确认保护的高级写入模式。差异化优势是手机直接连接数据库，不依赖后端代理，同时把安全门与移动输入效率放在同等优先级。

成功指标包括：新用户从选择连接到首次成功查询的中位时间低于 30 秒；`FROM/JOIN` 元数据联想命中率超过 90%；移动端查询取消可见反馈低于 500ms；误连生产库或误触高级写入的阻断率达到 100%；核心控件触控区域不小于 44px。

### FAQ

- **会取代现有接口吗？** 不会。原型重组信息架构，继续映射 `connections`、`metadata`、`query`、`cancel`、`history`、`savedSql` 和导出能力。
- **联想从哪里来？** 数据库、Schema、表/视图和字段来自原生元数据接口；SQL 关键词由本地编辑器词典提供。
- **为什么结果区不做全屏？** 高频任务是边看 SQL 边核对少量结果。大结果仍可通过拖拽分隔条或独立查看态扩展。
- **如何防止危险写入？** 默认只读安全执行；高级模式继续要求连接可写、本次确认，生产库还要输入连接名确认。

## 需求与信息架构

Must：连接上下文、多标签编辑、语法高亮、上下文联想、运行/取消、结果表格、错误与空态、安全执行。Should：Explain、参数、格式化、历史/收藏、导出、Schema Assist、分页。Could：图表、列宽自适应、单元格更新 SQL 草稿。Won't：后端代理、账号系统、任意 Redis 命令文本。

核心路径：选择连接 → 选择数据库/Schema → 输入 SQL 并接受元数据联想 → 运行所选 → 查看结果/消息/计划 → 导出或继续编辑。

## 接口映射

| 原型功能 | 现有实现 |
| --- | --- |
| 连接列表与切换 | `listDirectConnections` / 原生安全存储 |
| 数据库、Schema、表、视图、字段 | `loadDirectMetadata` |
| 执行与分页 | `executeDirectQuery` |
| 取消 | `cancelDirectQuery` |
| Explain | `explainDirectQuery` |
| SQL 联想与格式化 | `sqlSuggestions` / `formatSql` |
| 参数 | `resolveSqlParameters` |
| 结果导出 | `exportQueryResult` |
| 历史与收藏 | `history.ts` / `savedSql.ts` |

## 视觉系统

灵感转译取自 Dieter Rams 的功能层级、Otl Aicher 的符号秩序和 Naoto Fukasawa 的低干扰触感；不复刻具体作品。沿用系统变量：主色 `#0878ff`、背景 `#f5f7fa`、表面 `#ffffff`、边框 `#e1e7ee`、成功 `#159455`。间距以 4/8px 为基准，控件圆角 7–10px，抽屉圆角 20px，正文使用系统无衬线，SQL 使用系统等宽字体。

打开 `index.html` 可查看 430×900 Android 高保真交互原型。
