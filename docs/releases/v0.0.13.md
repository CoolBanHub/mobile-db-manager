# Mobile DB Manager v0.0.13

本版本优化移动端浏览流程的页面连续性，并保持 Android 手机端原生直连、本机安全存储和发布签名边界不变。

## 连接首页

- 按移动端原型移除连接首页重复的 “Mobile DB / 连接” 标题栏，让页面直接进入更新提示和连接搜索工具区。
- 数据库浏览页仍保留当前连接名称、主机端口和返回按钮。

## 数据库浏览

- 展开数据库节点时不再用全页加载状态替换对象树，搜索、筛选、数据库列表和当前页面位置保持不变。
- 已读取的数据库对象在当前页面内缓存；折叠后重新展开不会重复请求 Schema、表和例程。
- Schema 切换、手动刷新和加载更多表使用局部状态，并避免迟到请求覆盖当前数据库。

## 表数据分页

- 首次进入表详情仍显示完整加载状态；上一页、下一页、筛选和排序只更新表格数据区域。
- 翻页时保留标题、工具栏、当前表格、分页栏和编辑区，并显示目标页局部加载提示。
- 分页请求失败时保留当前页数据，提供目标页局部重试入口。

## 验证

- 通过 42 项前端单元测试。
- 通过 TypeScript 类型检查和 Vite 生产构建。
- 通过 Android 单元测试和完整 Debug APK 构建。
- 在 Android API 36 模拟器验证 MySQL 数据库节点缓存，以及 `performance_schema` 多页表的原位分页。

## 安装说明

- APK 支持 Android 8.0（API 26）及更高版本。
- 本版本继续使用与既有 GitHub Release 相同的签名证书，可从 `release/v0.0.12` 覆盖升级，也可被后续同证书 Release 覆盖更新。
- 本版本 Android `versionName` 为 `0.0.13`，`versionCode` 为 `14`。

## English summary

- Removed the redundant connection-home title bar while retaining connection context and back navigation inside database browsers.
- Kept the relational object tree mounted during database and schema loading, cached expanded database metadata, and protected the current selection from stale responses.
- Reworked table pagination, filtering, and sorting to update the data grid in place, with a localized loading overlay and retry state.
- Preserved direct-to-database execution, Android secure credential storage, read-only enforcement, Production confirmation, and the established Release signing certificate.
- Verified 42 frontend tests, the production web build, Android unit tests, a complete Debug APK build, and pagination against a multi-page MySQL `performance_schema` table.
