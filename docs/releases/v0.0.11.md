# Mobile DB Manager v0.0.11

本版本聚焦查询工作台体验和 Release 升级可靠性。

## 查询工作台

- 重构移动端 SQL 查询工作台布局，优化连接上下文、SQL 编辑器工具栏、结果网格、分页和导出操作。
- 新增查询入口空状态和快速创建查询流程，保留查询历史、收藏、Explain、取消和安全确认能力。
- 增强 SQL 上下文自动补全：在 `FROM` / `JOIN` 后联想表和视图，并根据已引用表联想字段。
- 更新 Redis、etcd 查询入口和结果展示的紧凑移动端交互。

## Release 升级可靠性

- 固定 Release 签名证书 SHA-256 指纹，记录在 `android/release-signing-cert.sha256`。
- GitHub Actions 在上传 APK 前校验证书指纹；如果发布 Secret 使用了错误或新证书，工作流会失败，避免产生无法覆盖安装的升级包。
- 继续使用 `release/vMAJOR.MINOR.PATCH` 生成单调递增的 Android `versionCode`。

## 验证

- 通过 41 项前端单元测试。
- 通过 TypeScript 类型检查和 Vite 生产构建。
- 通过 Android 单元测试和完整 Debug APK 构建。

## 安装说明

- APK 支持 Android 8.0（API 26）及更高版本。
- 覆盖安装必须使用与旧版本相同的 Release 签名证书。
- 本版本 Android `versionName` 为 `0.0.11`，`versionCode` 为 `12`。

## English summary

- Refreshed the mobile SQL workbench with a compact connection context, editor toolbar, result grid, pagination, export action, and a quick-create query landing state.
- Added contextual SQL completion for tables and views after `FROM` / `JOIN`, plus columns from referenced tables.
- Pinned the Release signing certificate SHA-256 fingerprint and made the GitHub Actions workflow fail before upload when a different keystore is used.
- Verified 41 frontend unit tests, the TypeScript/Vite production build, Android unit tests, and a complete Debug APK build.
