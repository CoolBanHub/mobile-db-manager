# Mobile DB Manager v0.0.7

本版本继续坚持 Android 手机端原生直连数据库，不引入后端服务、桌面代理或账号系统。

## 新增功能

- 新增 PostgreSQL、MySQL/MariaDB 和 SQL Server 可视化建表设计器，可配置字段、联合主键、索引、外键、检查约束、触发器、表选项和注释，并在查询工作台中预览 SQL 后执行。
- 新增独立设置中心，提供标准/紧凑界面密度、隐私与安全说明、应用版本信息以及手动检查 GitHub Release 更新入口。
- 新增可复用 SSH 跳板机配置。数据库连接只保存 SSH 配置 ID，密码、私钥和私钥口令继续由 Android Keystore AES-GCM 加密保存，不会返回 WebView。
- 连接列表新增开发、预发、生产环境标签和筛选；选择生产环境会同步开启原生生产写入保护。

## 修复与安全改进

- 修复 Android 上 jTDS SQL Server 驱动不支持 JDBC `Connection.isValid` 导致连接测试失败的问题，改用带超时的 `SELECT 1` 验证。
- 修正 PostgreSQL `SMALLINT` 自增字段生成 `SMALLSERIAL`，并加强建表字段长度、精度、索引、外键和 MySQL 表选项校验。
- SSH 配置切换认证方式时会删除不再使用的旧凭据；连接改用复用配置时会清理原有内联 SSH 凭据；正在被数据库连接引用的 SSH 配置不能删除。
- 保留应用启动时的后台更新检查，并在设置页提供手动检查入口。

## 安装说明

- APK 支持 Android 8.0（API 26）及更高版本。
- 覆盖安装必须使用与旧版本相同的发布签名证书。
- 安装包由 GitHub Actions 根据 `release/v0.0.7` 构建，Android `versionName` 为 `0.0.7`，`versionCode` 为 `8`。

## English summary

- Added a visual table designer for PostgreSQL, MySQL/MariaDB, and SQL Server.
- Added a Settings hub with interface density, security information, version details, and manual update checks.
- Added reusable SSH jump-host profiles whose credentials remain encrypted by Android Keystore and never return to the WebView.
- Added Development, Staging, and Production connection labels; Production now enables the native production write guard.
- Fixed SQL Server connection validation for the Android-compatible jTDS driver and strengthened table-definition validation.
