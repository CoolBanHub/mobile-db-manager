# Mobile DB Manager v0.0.12

本版本继续优化移动端连接目录和查询工作台，并保持 Android 手机端原生直连与本机安全存储边界不变。

## 连接目录

- 首页新增连接排序面板，支持按最近使用、连接名称、环境和置顶状态排列连接。
- 新增高级搜索，可按数据库类型、环境、连接方式、标签/分组、收藏和生产连接组合筛选。
- 连接偏好新增置顶和最近使用时间，并继续保存在本机 WebView 存储中。
- 连接卡片操作栏显示实际数据库名称；长名称保持单行省略，未指定数据库和不使用数据库的 etcd 提供明确状态。
- 原生连接摘要补充 SSH 和 HTTP CONNECT 状态，使连接方式筛选基于安全存储中的真实配置。

## 查询工作台

- 查询页使用移动端连接选择面板替代紧凑下拉框，展示连接名称、数据库、主机和端口。
- 优化数据库、Schema、表和集合上下文选择器，长名称自动省略且保持整行可点击。
- 调整查询标签、SQL 编辑器、工具栏和结果标签的紧凑布局，补充尚无查询结果和正在执行状态。
- 保留 SQL 执行、取消、Explain、历史、收藏、导出、只读限制和生产写入确认能力。

## 验证

- 通过 42 项前端单元测试。
- 通过 TypeScript 类型检查和 Vite 生产构建。
- 通过 Android 单元测试和完整 Debug APK 构建。
- 在 Android API 36 模拟器覆盖安装，并核对 PostgreSQL、MySQL、Redis、MongoDB、SQL Server 和 etcd 六类本机映射连接。

## 安装说明

- APK 支持 Android 8.0（API 26）及更高版本。
- 覆盖安装必须使用与旧版本相同的 Release 签名证书。
- 本版本 Android `versionName` 为 `0.0.12`，`versionCode` 为 `13`。

## English summary

- Added recent, name, environment, and pinned sorting plus advanced connection search by database type, environment, transport, tag/group, favorite, and Production state.
- Displayed the configured database name in connection card actions and included native SSH/HTTP proxy state in non-sensitive connection summaries.
- Reworked query connection and context selection for compact mobile use, with clearer empty and executing result states.
- Preserved direct-to-database execution, Android secure credential storage, read-only enforcement, and Production confirmation safeguards.
- Verified 42 frontend tests, the production web build, Android unit tests, a complete Debug APK build, and all six supported database families in the Android emulator.
