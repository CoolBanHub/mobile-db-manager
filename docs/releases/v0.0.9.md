# Mobile DB Manager v0.0.9

本版本继续坚持 Android 手机端原生直连数据库，不引入后端服务、桌面代理或账号系统。v0.0.9 重点补齐关系型数据库的移动运维诊断与安全编辑闭环，并收紧高级 SQL 的原生安全门，适用于 PostgreSQL、MySQL/MariaDB 和 SQL Server。

## 新增功能

### 会话、正在执行的 SQL 与锁诊断

- 在关系型数据库浏览页新增“会话与锁”入口，可查看全部会话、正在执行的 SQL、超过 30 秒的长查询或长事务、锁等待和阻塞链。
- 会话列表展示会话 ID、账号、数据库、客户端、状态、命令、查询文本、事务开始时间、等待类型和持续时间；页面默认每 15 秒自动刷新，也支持手动刷新。
- PostgreSQL、MySQL/MariaDB 和 SQL Server 使用各自固定的原生诊断 SQL，WebView 只能选择受支持的动作，不能向诊断接口下发任意管理 SQL。
- 支持取消 PostgreSQL、MySQL/MariaDB 当前 SQL，以及终止 PostgreSQL、MySQL/MariaDB、SQL Server 会话。SQL Server 不提供“仅取消 SQL”，避免把终止会话错误描述为轻量操作。
- 会话操作继续遵守连接安全属性：只读连接只能查看，不能取消或终止；生产连接必须再次输入完整连接名称并确认可能导致事务回滚。
- 数据库账号仍需具备相应监控或管理权限，例如 PostgreSQL `pg_read_all_stats`、MySQL `PROCESS`，以及 SQL Server `VIEW SERVER STATE` / `VIEW SERVER PERFORMANCE STATE`。

### 安全事务编辑模式

- 表数据新增、单元格修改和整行删除不再立即写库，而是先加入本机待提交队列；用户可继续编辑、逐项移除、全部撤销，并在统一检查页查看执行顺序。
- 同一批 INSERT、UPDATE、DELETE 由 Android 原生侧在一个 JDBC 事务内执行。任何操作失败，或更新/删除未恰好影响一行，整批操作都会回滚。
- 原生提交前重新读取数据库字段和主键定义，拒绝不存在的字段、缺失或不匹配的主键、主键字段修改以及不支持的数据库类型。
- 所有字段值通过 `PreparedStatement` 参数绑定；schema、表名和字段名按数据库方言安全转义，WebView 不再生成表数据写入 SQL。
- 没有主键的表保持不可编辑；只读连接禁止提交；生产连接必须勾选事务确认并输入完整连接名称。单批最多提交 100 项变更。
- 表格会标记待修改单元格和待删除行；存在未提交变更时禁止翻页、调整筛选或排序，防止页面上下文变化导致错误定位。

## 安全修复

### 高级 SQL 安全门收紧

- 修复高级 SQL 可能利用“看起来像只读”的语句绕过只读连接和生产确认的问题。`SELECT nextval(...)`、SQL Server `SELECT ... INTO ...` 或调用具有副作用的数据库函数，不再因为以 `SELECT` 开头而跳过高级模式保护。
- 所有高级 SQL 现在一律按可能写入处理：只读连接完全禁止高级模式；普通连接每次执行前必须明确勾选确认；生产连接还必须输入完整连接名称。
- 安全判断同时在查询工作台和 Android 原生插件执行。即使绕过前端界面直接调用 Capacitor 桥，原生侧仍会拒绝未确认、只读连接或生产名称不匹配的高级请求。
- 高级 SQL 的确认状态改为单次有效：执行结束或切换安全/高级模式后自动清空，不能沿用到下一条 SQL。
- SQL 关键词分类器只用于安全模式额外拒绝明显写入语句，不再决定高级模式是否需要只读、写入或生产连接校验。

## 测试与兼容性

- 新增会话活动识别测试，覆盖正在执行、Sleep/idle 会话和 idle in transaction 长事务。
- 新增固定诊断 SQL、正整数会话 ID、事务字段类型转换、SQL 参数占位符和数据库标识符转义测试。
- 新增高级 SQL 安全回归测试，覆盖副作用 SELECT、SQL Server `SELECT INTO`、只读连接拒绝、单次确认和生产连接名称精确匹配。
- 已通过前端单元测试、TypeScript 类型检查、Vite 生产构建、Android 单元测试和完整 Debug APK 构建。

## 安装说明

- APK 支持 Android 8.0（API 26）及更高版本。
- 覆盖安装必须使用与旧版本相同的发布签名证书。
- 安装包由 GitHub Actions 根据 `release/v0.0.9` 构建，Android `versionName` 为 `0.0.9`，`versionCode` 为 `10`。
- 发布工作流会运行前端测试、Capacitor Android 同步和 Android 单元测试，随后构建签名 Release APK、验证 APK 签名并上传到对应 GitHub Release。

## English summary

- Added PostgreSQL, MySQL/MariaDB, and SQL Server session diagnostics for running SQL, long transactions, lock waits, and blocking chains.
- Added guarded query cancellation and session termination; read-only connections cannot perform administrative actions, and Production requires exact-name confirmation.
- Added a staged table editor that reviews INSERT, UPDATE, and DELETE operations before committing them atomically in one native JDBC transaction.
- Native table mutations reload live metadata, require primary keys, bind all values with `PreparedStatement`, reject primary-key edits, and roll back the entire batch on any mismatch or failure.
- Fixed an advanced-SQL safeguard bypass where side-effecting SELECT statements could avoid read-only and Production checks.
- Advanced SQL is now always treated as potentially writable, blocked on read-only connections, protected by one-shot confirmation, and guarded again by the native Capacitor plugin.
- Added regression tests for diagnostic queries, session IDs, transaction value binding, identifier escaping, side-effecting SELECT statements, and exact Production confirmation.
