# Mobile DB Manager v0.0.10

本版本继续坚持 Android 手机端原生直连数据库，不引入后端服务、桌面代理或账号系统。v0.0.10 以移动端数据库工作流原型为设计基准，统一重构应用壳、连接管理、数据库浏览、查询工作台和安全设置，同时新增可复用的独立 SSH 密钥库。

## 移动端界面与交互升级

- 重构应用壳、顶部栏和底部导航，统一安全区、页面间距、卡片、输入框、按钮、状态颜色、弹窗、Bottom Sheet、空状态、加载状态和错误反馈。
- 新增可复用的顶部栏、底部导航、确认框、Sheet、页面状态和内联下拉框组件；保持原有页面历史栈、Android 返回键、滚动位置和应用更新逻辑。
- 连接列表升级为移动端卡片布局，统一搜索、收藏、环境筛选、分组和状态标签；连接编辑改为四步式流程，继续复用原有测试、保存、删除、SSL、SSH、HTTP 代理和安全字段逻辑。
- 所有页面以 320–430 px Android 手机宽度为主要适配范围，普通页面禁止非预期横向滚动；表格、SQL 编辑器、JSON 和长值继续在局部容器内滚动。

## 数据库浏览升级

- 关系型浏览页重新组织数据库、schema、表、视图、函数、存储过程和序列的层级与缩进，补齐搜索、筛选、排序、按名称渐进加载和对象统计。
- 表详细页重构工具栏、数据网格、横向滚动、分页和事务操作区；新增行、撤销、检查并提交仍使用原有原生事务和安全确认流程。
- Redis 浏览页改为原型一致的类型、逻辑库下拉选择和紧凑键列表，保留 SCAN 游标分页、TTL、固定动作和只读限制。
- MongoDB 浏览页统一数据库、集合和文档列表结构；etcd 浏览页统一前缀搜索、键空间统计和键值列表布局。
- 建表设计器、会话诊断、不支持状态以及危险操作提示使用同一套移动端视觉规则。

## 查询工作台升级

- 重新布局查询上下文、标签页、SQL 编辑器工具栏、运行状态和结果区域，窄屏下仍可操作执行、取消、Explain、分页、导出、历史和收藏。
- 查询结果拆分为独立面板，统一列头、数据单元格、空结果、错误反馈、分页和局部横向滚动。
- 安全模式、高级 SQL 确认、只读连接限制和生产连接名称确认保持不变，原生安全门不因界面重构而放宽。

## SSH 密钥与跳板机安全管理

- 新增独立 SSH 密钥库，一把密钥可以被多个跳板机通过 `keyId` 复用；设置页只展示密钥名称、算法、公钥 SHA256 指纹、口令状态和引用数量。
- 支持通过 Android 系统文件选择器导入 OpenSSH/PEM 私钥。文件内容直接进入原生保险箱，原生侧限制文件大小、校验私钥与口令并计算公钥指纹，不把私钥内容返回 WebView。
- 私钥和口令继续由 Android Keystore AES-GCM 加密保存；正在被跳板机引用的密钥不能删除，正在被数据库连接引用的跳板机仍不能删除。
- 旧版本内嵌在跳板机记录中的私钥会在首次读取时迁移到独立密钥库，跳板机 ID 保持不变，已有数据库连接无需重新绑定。
- 设置页统一为“安全与连接”界面，集中管理 SSH 密钥和跳板机，并补齐卡片边框、操作栏分割线、按钮尺寸、编辑与删除确认反馈。

## 测试与兼容性

- 新增 SSH 私钥解析与 SHA256 指纹测试，并继续覆盖 SQL 安全分类、查询参数、连接安全属性和原生事务逻辑。
- 已通过 40 项前端单元测试、TypeScript 类型检查、Vite 生产构建、Capacitor Android 同步、Android 单元测试和完整 Debug APK 构建。
- 已在 Android API 36 模拟器覆盖安装，并真实验证 PostgreSQL、MySQL（SSH 跳板机）、SQL Server、Redis、MongoDB 和 etcd 六类连接。

## 安装说明

- APK 支持 Android 8.0（API 26）及更高版本。
- 覆盖安装必须使用与旧版本相同的发布签名证书。
- 安装包由 GitHub Actions 根据 `release/v0.0.10` 构建，Android `versionName` 为 `0.0.10`，`versionCode` 为 `11`。
- 发布工作流会运行前端测试、Capacitor Android 同步和 Android 单元测试，随后构建签名 Release APK、验证 APK 签名并上传到对应 GitHub Release。

## English summary

- Rebuilt the mobile shell, navigation, spacing, cards, forms, dialogs, sheets, and shared page states around the repository's Android-first workflow prototype.
- Upgraded connection cards, filtering, grouping, and the four-step connection editor while preserving all existing direct-connect, SSL, SSH, proxy, and safety behavior.
- Redesigned relational metadata browsing, table data, Redis, MongoDB, and etcd pages with clearer hierarchy, inline selectors, narrow-screen tables, and localized horizontal scrolling.
- Extracted a reusable query result panel and refreshed the SQL workbench without changing execution, cancellation, Explain, export, history, saved SQL, read-only, or Production safeguards.
- Added a reusable SSH key library with Android document-picker import, native key/passphrase validation, SHA256 public-key fingerprints, Android Keystore encryption, reference guards, and automatic migration of legacy embedded keys.
- Verified 40 frontend tests, the production web build, Android unit tests, a complete Debug APK build, and live emulator connections to all six supported database families, including MySQL through an SSH jump host.
